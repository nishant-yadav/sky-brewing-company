# Coffee Roastery Website

A simple Astro static website scaffold based on the recommended solution.

## What is implemented

- Astro static site
- Tailwind CSS styling
- Home, About, and Contact pages
- Minimal layout and responsive design
- Easy deployment to GitHub Pages, Cloudflare Pages, or Vercel

## Prerequisites

- Node.js 18 or newer
- npm, Yarn, or pnpm
- Git (optional but recommended)

## Setup

1. Install dependencies:
   - `npm install`
2. Start the development server:
   - `npm run dev`
3. Build for production:
   - `npm run build`
4. Preview the production build:
   - `npm run preview`

## Deployment

Recommended hosting:

- Cloudflare Pages
- Vercel
- GitHub Pages

A static Astro site is a good fit for a website that changes only every few months.

## Notes

- Content can be updated directly in `src/pages/*.astro`.
- For non-technical editing later, add a headless CMS such as Sanity or Decap CMS.
